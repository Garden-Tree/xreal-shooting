# XREAL Shooting

XREAL ARグラス（Beam Pro コントローラー）向けの **ARシューティングゲーム** です。
オープンキャンパスの体験展示用に制作されたもので、プレイヤーの周囲360°から迫ってくる的を、コントローラーから発射する弾で撃ち落としてスコアを競います。

> 来場者が短時間で気軽に遊べるよう、キャリブレーション → 難易度選択 → プレイ → リザルトまでを画面タップ（トリガー）だけで一周できる構成になっています。

## 遊び方

1. **キャリブレーション** — 「真正面に Beam Pro を向けて、画面をタップ」してください。コントローラーの正面方向が基準としてリセンターされます。
2. **難易度選択** — 目の前に表示される `EASY` / `NORMAL` / `HARD` の的を撃つと、その難易度でゲームが始まります。
3. **プレイ（制限時間30秒）** — 周囲から近づいてくる的を撃ち落とします。画面端のインジケーターが一番近い的の方向を示します。
4. **リザルト** — 時間切れまで耐え抜くと **GAME CLEAR**、ライフが尽きると **GAME OVER**。画面タップで再挑戦できます。

### 操作

| 入力 | アクション |
| --- | --- |
| トリガー（画面タップ） | 射撃 / 各種決定 |
| App ボタン | ゲームを最初（キャリブレーション）に手動リセット |

### スコアと難易度

| 行動 | スコア |
| --- | --- |
| 的に命中 | **+100** |
| 弾が外れる（射程到達） | **−10** |
| 的にプレイヤーへ到達される（被弾） | **−100** & ライフ −1 |

| 難易度 | 出現間隔 | 同時出現数 | ライフ |
| --- | --- | --- | --- |
| EASY | 2.0秒 | 2 | 5 |
| NORMAL | 1.5秒 | 3 | 3 |
| HARD | 0.8秒 | 5 | 1 |

> 制限時間（30秒）などの値は `GameManager` のインスペクターから調整できます。

## 主な特徴

- **360°シューティング** — プレイヤーを中心とした円周上に的が出現し、直線・ジグザグ・螺旋の3パターンで接近します。
- **エイムアシスト付き射撃** — 弾は SphereCast による太めの当たり判定で飛翔するため、AR環境でも狙いやすくなっています。着弾予想位置にはレティクル（ドット）を表示。
- **没入演出** — フラッシュライト風のボリュメトリックな光線、トレイル付きの弾、命中時のハプティクス（振動）、スコアのフローティングテキスト、クリア時の紙吹雪と虹色テキストアニメーション。
- **オブジェクトプール** — 的は使い回し（プール）で生成・破棄のコストを抑えています。
- **BGM / SE** — 任意区間でのカスタムループに対応した BGM、射撃・命中・被弾・クリア各種の効果音。

## プロジェクト構成

ゲーム本体のスクリプトは `Assets/Scripts/` 以下にあります。

| ファイル | 役割 |
| --- | --- |
| [GameManager.cs](Assets/Scripts/GameManager.cs) | ゲーム全体の状態遷移（キャリブレーション→難易度選択→プレイ→終了）、的のスポーン、スコア・ライフ・タイマー、UI、BGM管理 |
| [BeamProController.cs](Assets/Scripts/BeamProController.cs) | Beam Pro のポインター制御、射撃入力、フラッシュライト描画、レティクル、ハプティクス |
| [Projectile.cs](Assets/Scripts/Projectile.cs) | 発射される弾の飛翔と衝突判定、命中/外れ時の処理 |
| [TargetObject.cs](Assets/Scripts/TargetObject.cs) | 的の移動パターン、被弾・到達処理、プール再利用 |
| [DifficultySelectTarget.cs](Assets/Scripts/DifficultySelectTarget.cs) | 難易度選択用の的（撃つとゲーム開始） |
| [FloatingText.cs](Assets/Scripts/FloatingText.cs) | スコア加減算のフローティングテキスト表示 |

- メインシーン: `Assets/Scenes/main.unity`
- 入力定義: `Assets/XREAL Actions.cs`（Input System のアクションマップ）

## ビルド方法

1. Unity `6000.0.73f1` でプロジェクトを開く。
2. `Packages/manifest.json` の XREAL SDK のパスを自環境に合わせる。
3. プラットフォームを **Android** に切り替える（`File > Build Settings`）。
4. `Assets/Scenes/main.unity` をビルド対象シーンに設定してビルド。
5. 生成された APK を XREAL の対応端末（Beam Pro 等）にインストール。
